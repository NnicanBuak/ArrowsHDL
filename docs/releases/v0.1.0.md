# ArrowsHDL v0.1.0

Первый экспериментальный выпуск компилятора Verilog/SystemVerilog в физические схемы Logic Arrows.

- CLI и Python API для компиляции, сборки, проверки и симуляции.
- `project.toml` v3 и необязательный `design.toml` для интерфейсов и размещения.
- `--layout compact`, кеширование модулей, игровые сохранения `.txt` и `--preview PNG`.
- Нативные компоненты, память и дисплеи; четыре самостоятельных примера с независимыми регрессиями.

## Пакеты и установка

Нужны **Python 3.11+ и pip**. Пакеты для четырёх платформ:

| Платформа | Окончание имени wheel |
| --- | --- |
| Windows x64 | `win_amd64.whl` |
| Linux x64 | `manylinux_2_17_x86_64.whl` |
| macOS 14+ Intel | `macosx_14_0_x86_64.whl` |
| macOS 14+ Apple Silicon | `macosx_14_0_arm64.whl` |

Скачайте подходящий файл из
[Assets релиза](https://github.com/NnicanBuak/ArrowsHDL/releases/tag/v0.1.0):

~~~powershell
python -m pip install "ПУТЬ_К_СКАЧАННОМУ_WHEEL.whl"
arrowshdl health
~~~

Нативный движок включён в каждый wheel: Linux использует статический musl-бинарник,
Windows — статическую компоновку C runtime. Yosys, Node.js и Pillow устанавливаются
через pip; **компиляторы и Rust/Cargo для установки wheel не требуются**.

Для каждого пакета выполняются аудит ресурсов, проверка установки вне каталога
исходников и короткие проверки CLI, Python API и нативного движка. `SHA256SUMS.txt` содержит
SHA-256 всех четырёх wheel.

Поддержка HDL **экспериментальная**: синтезируется поддерживаемый комбинационный поднабор,
а память задаётся нативными модулями. Подробности — в [справочнике](../reference.md),
примеры — в [README](../../README.md#примеры).
