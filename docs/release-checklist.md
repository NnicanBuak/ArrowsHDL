# Критерии готовности 0.1.0

Проверка выполняется локально. Публикация во внешние сервисы в задачу не входит.

1. **Установка и интерфейс.** Установка из репозитория в чистое окружение;
   импорт публичного API из другого каталога; CLI и `python -m arrowshdl`;
   compile, link, build, test, simulate, encode, decode, graph, preview.
   Публичный ассемблер исключён согласно последующему уточнению пользователя.
2. **Компиляция.** Несколько файлов, include, параметры, библиотеки, иерархия,
   отдельные объекты с версией и проверкой интерфейсов; явные ошибки для
   неподдерживаемой последовательной логики; единый бюджет времени сборки.
3. **Нативная семантика.** SET, TOGGLE, RANDOM, фронты, таймеры, кнопки,
   индикаторы; память и импульсы не подвергаются булевой оптимизации;
   физические контакты и временные ограничения проверяются после размещения.
4. **Примеры.** Логика на Verilog, общие команды, один финальный комплект
   артефактов на схему, без исполняемых скриптов в examples; регрессии в tests.
5. **Сапёр.** Сохранения V1 из previous-112 побайтно неизменны, исходники
   воспроизводят клетки; V2 <=56×64 и <=2164 стрелок на ячейку, поля не хуже
   исходной компактной сборки; перебор соседей, переходы, все кнопки, поля
   3×3/5×5/10×10, два seed, поздние/одновременные клики, каскад, победа, поражение.
6. **Доказательства.** Отчёты содержат SHA-256 проверенного сохранения;
   ограничения V1 отражены в документации, старые отчёты не переиспользуются.
7. **Очистка.** Нет зависимостей от удалённых архивов и сборщиков, потребители
   map-life используют пакет, остальные проекты сохранены.
8. **Документация и лицензия.** Русский quick start, каталог реально собранных
   схем, справочник CLI/API/Verilog/TOML/IR/симулятора/диагностики; ссылки
   проверены; PolyForm Noncommercial 1.0.0 и Required Notice Nnican;
   сохранено авторство стороннего кода; нелицензированный адаптер заменён.

Финальный результат оценивается по каждому пункту. Непройденные проверки
исправляются или явно описываются с привязкой к конкретному артефакту.

## Итог проверки

Локальные критерии выполнены: **122 общие регрессии и 2 новые исчерпывающие проверки**, 4 проекта с визуализациями, обе версии сапёра, точные хеши и ссылки.
Установка из исходников и Windows x64 wheel проверена в отдельных чистых
окружениях. Публичные команды и API проверены из другого каталога.
[Машиночитаемый отчёт](release-report.json) содержит размеры и SHA-256.

Ограничения: экспериментальный HDL-поднабор, неподтверждённая работа на
других платформах и исторические особенности V1. Перед внешней публикацией
нужно решить вопрос прав на сторонние игровые ресурсы и учебные фрагменты;
[подробности](../THIRD_PARTY_NOTICES.md). Публикация не выполнялась.

Для повторения проверки установленного пакета создайте чистый venv вне
checkout, установите пакет через pip и из внешнего каталога запустите
`python /абсолютный/путь/ArrowsHDL/tools/check_installation.py /абсолютный/путь/ArrowsHDL`.
Скрипт создаёт проверочные схемы в текущем каталоге и локальный отчёт в build.
Полные регрессии: `arrowshdl test --suite tests -o build/regression.json`.
Аудит текущих отчётов и ссылок: `python -m tools.check_release` из корня.
