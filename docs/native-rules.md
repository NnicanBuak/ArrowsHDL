# Правила нативных стрелок

Профиль: GraphDLC `01232bdef7d0d399432ddd1a5a5f57e9fcbd4d1b`.
Правила подтверждаются `tests/test_simulator.py` и `tests/test_native_rules.py`
с независимой поклеточной моделью и настоящим Rust-ядром.

Все стрелки обновляются по состоянию **предыдущего игрового такта**.
Сигнал передаётся только при активном состоянии 1; внутреннее ожидающее
состояние 2 не равно обычному логическому уровню.

| Тип | Правило |
|---:|---|
| 1 | Передаёт ИЛИ входящих сигналов вперёд |
| 2 | Постоянный источник во все четыре стороны |
| 3 | Блокирует обновление клетки перед собой, когда активен |
| 4 | Задержка с внутренним ожидающим состоянием |
| 5 | Читает состояние клетки позади себя, включая ожидающее |
| 6–8 | Обычное ИЛИ с несколькими выходными направлениями |
| 9 | Однократный стартовый импульс; затем ожидающее состояние |
| 10–14 | Прыжки и разветвления с заданной геометрией |
| 15 | НЕ: активен без входящего сигнала |
| 16 | Порог: активен при двух и более входящих сигналах |
| 17 | Нечётность числа входящих сигналов |
| 18 | SET: при входе сохраняет 1 для двух и более сигналов, 0 для одного; без входа держит состояние |
| 19 | TOGGLE на каждом такте с входящим сигналом |
| 20 | RANDOM с заданным seed |
| 21 | Интерактивная кнопка без направленного HDL-входа; в headless-профиле не нажата |
| 22 | Тестовый Source, объединяющий внешнее управление с входящим сигналом |
| 23 | Тестовый Target, принимает и не передаёт сигнал |
| 24 | Направленная кнопка; headless-вход реализуется явной тестовой подстановкой |
| 25 | Пассивная клетка, всегда 0, без передачи сигнала |

Поворот и отражение меняют геометрию. Прыжки не соединяются с промежуточной
клеткой. Блокиратор и детектор создают семантические зависимости, отличающиеся
от обычных выходных контактов; `native_rules.dependency_links` учитывает их.
Детектор не принимает обычные входы, генераторы не зависят от них.

Порог type 16 не равен многовходовому логическому И: для AND нужны ровно
два входа, для MAJ — три. На клетке остаётся не более 11 входных контактов,
поскольку требуется выход. Обратные связи являются настоящей памятью,
а не ошибкой физического графа. Временные контракты должны учитывать
границы памяти и тактовые задержки.

RANDOM, SET, TOGGLE и импульсы нельзя сливать как обычные одинаковые булевы
узлы. При автоматическом размещении сохраняются внутренние связи нативных
макросов, а внешний путь может увеличить задержку. Для игровых протоколов
с закреплённым временем используется HDL с отдельной физической геометрией.
