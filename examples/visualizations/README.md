# Circuits

[Все готовые схемы](build/index.html): текущие сохранения двенадцати HDL-примеров
и [одноразрядный индикатор 0–7](../digit3/README.md), всего 13 схем.
Исторические сборки и схемы без физической карты в галерею не включены.
Для BCD готова карта `bcd4`; `bcd8` пока имеет только доказательство HDL.
АЛУ4/АЛУ8 пока не имеют готовых физических сохранений.

`mul4_tree` — многомодульный умножитель с тремя сумматорами, 511 клеток.
`mul4_flat` — прежний отдельный пример прямого умножения, 992 клетки.
Суффиксы различают два самостоятельных примера, а не обозначают режим сборки.

Визуализации содержат только английское название и легенду. В схемах,
имеющих метаданные цепей, доступны полный вид разводки, окно ядра,
цвета цепей и интерактивный просмотр по нажатию на изображение.
Старые примеры без метаданных цепей используют цвета типов клеток;
нажатие открывает изображение в полном разрешении.
Логические элементы выделены тонкой белой обводкой, проводники затемнены.

Генератор читает Base64 и проверяет хеш карты перед отрисовкой.
Исходники схем, карты и результаты физических испытаний не изменяются.

```powershell
python ArrowsHDL/examples/visualizations/build_gallery.py
```
