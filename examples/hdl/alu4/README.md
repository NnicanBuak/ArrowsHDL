# ALU4

Многомодульная 4-битная АЛУ. Входы `a`, `b`, `op`; выходы `result`,
`carry_borrow` и `zero`. Арифметика беззнаковая, результат ограничен четырьмя битами.

| op | Операция |
|---:|---|
| 0 | A + B |
| 1 | A − B |
| 2 | A AND B |
| 3 | A XOR B |
| 4 | A OR B |
| 5 | A << 1 |
| 6 | A >> 1 |
| 7 | NOT A |

`carry_borrow` показывает перенос при сложении и заём при вычитании;
для остальных операций равен нулю. `zero` показывает нулевой результат.

Сумматор вложен в арифметический модуль; логика, сдвиги и декодер операции
соединены модулем выбора результата. Явно заданы три отдельные шины `a`, `b`, `op`, все с автоматическим шагом.

Подготовлен независимый эталон Python: все **2048** входных сочетаний,
960 векторов переключений операций и 4096 случайных векторов.
**Функция HDL доказана для всех 2048 сочетаний. Компактная физическая
сборка пока не получена.** Резервное размещение смогло соединить ядро из
781 клетки с глубиной 81 тик; последующий поиск более плотной компоновки
не дал готового результата. Сохранение и физические отчёты не созданы.
Готовый многомодульный пример — [умножитель 4×4](../candidates/mul4/README.md).

```powershell
python ArrowsHDL/examples/hdl/alu4/testbench.py
```
