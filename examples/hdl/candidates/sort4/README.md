# Сортировщик четырёх 4-битных чисел

[Полный Verilog](sort4.v) содержит компаратор, мультиплексор,
блок сравнения/обмена и верхний `sort4`.
Сеть использует **пять экземпляров блока сравнения/обмена** в трёх слоях.
Внутри каждого блока — один компаратор и два мультиплексора.

Входы: `x0`, `x1`, `x2`, `x3` — четыре беззнаковых 4-битных слова.
Выходы: `y0`, `y1`, `y2`, `y3` — те же числа по возрастанию.
Повторяющиеся значения сохраняются.

| Входы | Выходы |
|---|---|
| 9, 2, 15, 7 | 2, 7, 9, 15 |
| 4, 4, 1, 4 | 1, 4, 4, 4 |
| 0, 0, 0, 0 | 0, 0, 0, 0 |

**Что проверяет компилятор:** разветвление сигналов, перекрёстные связи между
слоями и множество мультиплексоров. Это самый большой из трёх графов:
**296 узлов**, включая 16 выходных буферов. Всего **65 536** входных наборов;
независимый эталон физического теста — `sorted()` в Python.

[Отчёт проверки HDL](check/sort4.check.json) ·
[проверяемая спецификация](check/specification.v) · [журнал SAT](check/sat.txt).
SAT доказал порядок выходов и сохранение количества каждого входного значения
для всех наборов. Размещение и задержка стрелок проверяются на следующем этапе.
