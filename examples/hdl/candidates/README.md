# Варианты схем из нескольких модулей

Подготовлены полные исходники Verilog. Все используют комбинационные
`assign`, фиксированную разрядность и иерархию в одном файле.
**Исходники прошли адаптер ArrowsHDL и доказательство функциональных свойств
Yosys SAT.** Умножитель уже собран и проверен на карте стрелок;
сортировщик расширен до четырёх **8-битных** чисел, но физическая трассировка
пока завершилась отказом — причины записаны в его README и отчёте.

| Вариант | Основные блоки | Узлов после Yosys | Комбинаций входов |
|---|---|---:|---:|
| [АЛУ 8 бит](alu8/README.md) · [код](alu8/alu8.v) | Сумматор, блок сложения/вычитания, AND/XOR, выбор результата, флаги | 151 | 262 144 |
| [Умножитель 4×4](mul4/README.md) · [код](mul4/mul4.v) | Частичные произведения и дерево из трёх сумматоров | 72 | 256 |
| [Сортировщик четырёх байтов](sort4x8/README.md) · [код](sort4x8/sort4x8.v) | Пять блоков сравнения/обмена; внутри каждого — компаратор и два мультиплексора | 592 | 2³² — символическое доказательство HDL |

Число узлов включает выходные буферы; **это не число стрелок**. Иерархия
разворачивается в один логический граф. Названия вложенных экземпляров и их
происхождение сохраняются в `scopes` и `instances`. Общий упаковщик размещает
операторы по этим блокам; небольшие тесно связанные модули могут объединяться.

АЛУ сохраняет знакомую 8-битную арифметику и добавляет логические операции,
общий управляющий сигнал, мультиплексоры и флаги.
Умножитель удобен для проверки взаимодействия нескольких сумматоров.
Сортировщик сильнее нагружает общую трассировку разветвлениями и перекрёстными связями.

## Проверки исходников

Команды из корня репозитория после [установки проекта](../../../README.md):

```powershell
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/check_source.py alu8
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/check_source.py mul4
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/check_source.py sort4
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/check_source.py sort4x8
```

Скрипт сохраняет граф, спецификацию, отчёт `.check.json` и журнал SAT в
подкаталог `check` соответствующего примера. SAT доказывает свойства для всех
входов символически; это проверка HDL, а не потактовая симуляция стрелок.
Отдельные `mul4/testbench.py` и `sort4x8/testbench.py` создают обычную и тестовую
карты после успешного размещения, добавляют Source/Target и сравнивают результаты
с Python `a*b` и `sorted()`. Умножитель прошёл 868 физических векторов;
86 984 вектора сортировщика подготовлены, но не исполнены из-за отказа трассировки.
Визуализация строится из экспортированного и заново прочитанного сохранения.
Старый [4-битный вариант сортировки](sort4/README.md) сохранён для сравнения.

При подготовке обнаружено и исправлено отклонение служебных `$scopeinfo`
адаптером. Эти записи сохраняют сведения об иерархии и не имеют электрических
портов. Записи с электрическими соединениями по-прежнему отклоняются.
