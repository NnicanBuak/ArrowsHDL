# Сортировщик четырёх 8-битных чисел

[Полный Verilog](sort4x8.v) содержит четыре типа модулей: компаратор,
мультиплексор, блок сравнения/обмена и верхний сортировщик. Пять блоков
сравнения/обмена соединены в три стадии; внутри каждого — компаратор
и два 8-битных мультиплексора. После разворачивания сохранены 20 вложенных
экземпляров в `scopes`.

Входы: `x0`, `x1`, `x2`, `x3`; выходы: `y0`, `y1`, `y2`, `y3`.
**Каждое число — беззнаковый байт 0–255.** Выходы идут по возрастанию,
повторяющиеся значения сохраняются. Схема комбинационная, без памяти.

| Входы | Выходы |
|---|---|
| 255, 2, 128, 7 | 2, 7, 128, 255 |
| 128, 127, 255, 0 | 0, 127, 128, 255 |
| 4, 4, 1, 4 | 1, 4, 4, 4 |

## Текущее состояние

**HDL верен, физическая карта пока не собрана.** Общий маршрутизатор
отклонил восемь штатных размещений (шаги 3–8) и дополнительную расстановку
с шагом 8 / seed=1. Плотные варианты расходуют бюджет перестройки;
в просторных возникают конфликты внутренних и внешних проводов.
[Отчёт с наблюдавшимися отказами](compile.failure.json) сохраняет исходник,
число узлов, параметры и причины отказа каждой попытки.

Исправлены избыточный поиск к недоступным входам и многократная перестройка
одних цепей; добавлен запасной совместный проход при конфликте внешних контактов.
Это ускоряет отказ, но пока не обеспечивает успешное размещение этой схемы.
**Сохранения, визуализации и результатов физической симуляции для неё нет.**

## Проверки

[Доказательство HDL](check/sort4x8.check.json) ·
[спецификация](check/specification.v) · [журнал Yosys SAT](check/sat.txt).
Доказаны порядок выходов и точное сохранение количества каждого входного
значения **для всех 2³² наборов входов**. Это символическое доказательство
HDL, а не полный перебор физической схемы.

[Отдельный тест](testbench.py) подготовлен для сравнения физических выходов
с Python `sorted()`; **его физический прогон ещё не выполнен**. Набор содержит
65 536 пар значений в первых двух компараторах, 4 096 граничных наборов,
72 перестановки, 512 случаев с повторами, 384 переключения одиночных битов
и 16 384 случайных/инвертированных наборов. Всего **86 984 вектора**.

Из корня репозитория после установки [ArrowsHDL](../../../../README.md):

```powershell
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/check_source.py sort4x8
ArrowsHDL/.venv/Scripts/python.exe ArrowsHDL/examples/hdl/candidates/sort4x8/testbench.py
```

`--reuse` проверяет уже собранную карту с контролем хешей исходника,
графа и сохранения. Source/Target добавляются к копии обычной карты;
исполняется повторно прочитанное Base64, ожидания вычисляются независимо.

После Yosys — **592 узла**, включая 32 выходных буфера.
