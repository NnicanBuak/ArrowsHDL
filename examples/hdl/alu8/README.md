# ALU8

Многомодульная 8-битная АЛУ. Входы `a`, `b`, `op`; выходы `result`,
`carry_borrow` и `zero`. Арифметика беззнаковая, результат ограничен восемью битами.

| op | Операция |
|---:|---|
| 0 | A + B |
| 1 | A − B |
| 2 | A AND B |
| 3 | A XOR B |
| 4 | A OR B |
| 5 | A << 1 |
| 6 | A >> 1 |
| 7 | NOT A |

`carry_borrow` показывает перенос при сложении и заём при вычитании;
для остальных операций равен нулю. `zero` показывает нулевой результат.

Сумматор вложен в арифметический модуль; логика, сдвиги и декодер операции
соединены модулем выбора результата. Явно заданы общая шина `a,b`
и отдельная управляющая шина `op`, обе с автоматическим шагом.

Подготовлен независимый эталон Python: все **524 288** входных сочетаний,
960 векторов переключений операций и 4096 случайных векторов.
**Функция HDL доказана для всех входов. Физическая сборка завершилась отказом**
на многоточечной трассировке; готовое сохранение не создано.
