# История версий

## [0.1.0] - 2026-10-13

**Первый экспериментальный выпуск ArrowsHDL.**

### Added

- Компиляция поддерживаемого Verilog/SystemVerilog в игровые сохранения Logic Arrows через CLI и Python API.
- HDL-проекты TOML v3: иерархия, параметры, интерфейсы и размещение через необязательный design.toml.
- Нативные модули памяти, генераторы, кнопки, индикаторы и дисплеи.
- Автоматическое размещение, дополнительный поиск через --layout compact и кеш готовых модулей.
- PNG-предпросмотр той же карты, объектная компиляция RTLIL и последующая компоновка.
- Физическая симуляция, проверка исходников по именованным векторам и команды преобразования сохранений.
- ALU Workbench, Packet Router, Pulse Sequencer и Minesweeper 10×10 с независимыми регрессионными тестами и изображениями.
- Сборки wheel для Windows x64, Linux x64 и macOS Intel/Apple Silicon со встроенным движком, проверкой установки и SHA-256.
