# Значки стрелок

Значки типов **1–25** получены из публичных ресурсов
[Logic Arrows](https://logic-arrows.io/) с параметром ресурса `v=1_4`:
`https://logic-arrows.io/res/sprites/arrow<ID>.png?v=1_4`.
Используются для изображения фактически сохранённых клеток; авторство графики
принадлежит создателям игры. Файлы не являются исходниками компилятора.
